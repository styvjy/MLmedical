# MLmedical
ML model can be used in hospital, Triage teams need fast preliminary screening of chest radiographs to flag abnormalities like pneumonia or tuberculosis.

## Collaboration
If you want to collaborate on this repository:

1. Fork the repository and create a feature branch.
2. Make focused changes with a clear commit message.
3. Open a pull request that explains what you changed and why.
4. Include validation details (tests, checks, or manual verification) in the pull request description.

Please read the contribution guide in `/home/runner/work/MLmedical/MLmedical/CONTRIBUTING.md` before opening a pull request.
